## 2. 土曜「宇宙銀行の窓口」コンセプト

**ねらい**：お金と向き合う＝自分と向き合い、気づきを増やす。BGMを流しながら、実践（手を動かす）を伴うワークの場にする。

**張り付かない設計**：ワークのテロップを3時間ループ素材に焼き込む。11時間配信なら 0:00・3:00・6:00・9:00 開始の約4回、自動で窓口が開く。

### 3時間ブロック内の時間割

| 時間 | ワーク | その場でやること | 動かすビリーフ |
|---|---|---|---|
| 0:00 | 開店の案内 | 紙とペンを用意 | ― |
| 0:10 | 財布の窓口整理 | レシートを出す・お札の向きを揃える・カードを1枚抜く（5分の作業画面） | ― |
| 0:30 | 記帳ノート | 今週受け取った小さなもの（お釣り・ポイント・おすそ分け・褒め言葉）を3つ書き、財布に挟む | 木「お金は苦労しないと入ってこない」 |
| 0:40 | 今週のラッキー | 小さなラッキーを1つ／当選したら最初にすること | 金「自分には運がない」 |
| 0:50 | 残高確認 | ①怖さを認める ②数字はあなたの価値ではない ③開く前に3回息を吐き「ありがとう」 ④見たら「ここから満ちていく」。チャットには「見ました」だけ（**金額は書かない**） | 日「お金のことを考えるのは怖い」／土「お金はいつか尽きる」 |
| 1:10 | 不安のお預け入れ | 不安を紙に書き、折りたたんでしまう。「宇宙銀行にお預けしました」 | 日 |
| 1:20 | 来週の宿題 | 次にお金を払うとき心の中で「ありがとう」 | ― |
| 1:30〜3:00 | 閉店・おやすみモード | 通常BGM | ― |

### 視聴者のビフォー → アフター（要約）
- 残高を見るのが怖い → 週1回、落ち着いて確認できる
- 「何も入ってこない」 → 「意外と受け取ってた」
- 寝る前にお金の心配が止まらない → 預けて手放して眠れる
- ひとことで：「BGMを流して待つ人」から「お金と向き合い、気づきを受け取れる人」へ

## 3. 立ち位置（ポジショニング）

- とがっている点：**「銀行」の言葉（預ける・記帳・残高・窓口・通帳）で、ふわっとした金運を具体的な行動に変えられる**／聞かなくていい・流すだけ／顔も声もない＝視聴者が主役／曜日で通う習慣
- ひとこと：「話を聞かなくていい。流しておくだけで、お金と向き合う習慣が身につく場所」
- 本人の立ち位置：**鳥居**（場を整えておく人）／「場を整えて、そっと案内する巫女さん」。神託を伝える・力で叶える巫女にはしない（開運商法に見えるため）。発信で名乗るのではなく、内側の軸として持つ
- 神社との対応：鳥居＝再生／手水＝財布整理／参拝＝残高・記帳／絵馬＝チャット／お焚き上げ＝お預け入れ／お賽銭＝スパチャ／お守り＝メンバーシップ
- 参考チャンネル10選はExcel参照（心屋仁之助、本田晃一、本田健、Kate Northrup、Denise Duffield-Thomas、「〜with me」系など）。BGM×張り付かないワークの組み合わせは見当たらず＝空いているポジション

## 4. Nightbot（2026-09-27 設定済み・動作確認済み）

- 宇宙銀行アカウントでログイン済み、チャンネル参加済み（Nightbot Online）、モデレーター済み（ライブで返信を確認）
- YouTubeでは**公開ライブ中のみ**動作（限定公開のテストでは動かない）
- コマンドは「メッセージの最初の言葉」が完全一致したときだけ反応。`!` なしの日本語名もOK

### 登録済みコマンド
| 名前 | 応答 | 設定 |
|---|---|---|
| 受け取ります | ✨受け取りました。あなたの申込書は宇宙銀行に届いています | みんな／クールダウン30秒 |
| 888 | ✨888 黄金の扉が開いています。豊かさが末広がりに広がっていきますように | みんな／クールダウン60秒 |
| 8888 | （別名→888） | |
| 88888 | （別名→888） | |

- 視聴者に案内する合言葉は「受け取ります」だけ（概要欄の既存導線と同じ）。888は案内しない隠れたおまけ
- 固定コメント案：「🏦 nightbotは宇宙銀行の案内係です。『受け取ります』と書くと、お返事が届きます✨」

### タイマー（未登録。水曜に土曜ライブの素の数字を見てから）
チャット行数は最小値、間隔30〜60分。
- welcome：✨宇宙銀行へようこそ。今夜は流したまま、おやすみくださいね

## 6. 収益化

- **大前提：「スパチャ／課金すると金運が上がる」とは言わない**。応援・感謝として受け取る（開運商法に見えない・YouTubeの誤解を招くコンテンツ規約対策）
- 優先順位：①メンバーシップ ②ワーク帳の商品化 ③スパチャ演出

### メンバーシップ「窓口会員」（案）
- 条件：YPP参加・18歳以上・子ども向け設定なし。**音楽の申し立て（Content ID）がある動画は対象外** → 事前に整理
- 最初は1レベルのみ（月290円前後）
- 特典：会員スタンプ（最初4個、48×48〜480×480px：金貨・扉・宝石・「受け取ります」）／継続バッジ（新規＝口座開設／1か月＝普通預金／2か月＝積立預金／6か月＝定期預金／1年＝金庫会員／2年〜＝宇宙金庫会員）／会員限定コミュニティ投稿 月1（ワークシート配布）／会員限定窓口ライブ 月1（素材使い回し）
- お迎えの一言：「宇宙銀行の窓口会員へようこそ。あなたの口座が開設されました✨」

### ワーク帳の販売先（チャンネル世代向け）
- ◎ **Amazon KDP（ペーパーバック＋Kindle）**：アカウント不要・紙に書き込める。本人はKindle出版経験あり → 第一候補
- ○ note：手取り約85%（決済5%＋利用料10%、振込270円）。PDF販売・会員特典向き
- △ BOOTH：5.6%＋45円（2025/10〜）。pixivアカウント必要・若年層向け
- 海外 Gumroad：10%＋$0.50＋決済手数料。海外BGM販売の候補

### スパチャ「宇宙銀行へのお預け入れ」
- OBSにアラート（Streamlabs等）→金貨演出＋「◯◯様のお預け入れを承りました✨」を自動表示
- 週1回まとめて「預金者名簿」エンドロールを翌週の窓口ライブ背景に
