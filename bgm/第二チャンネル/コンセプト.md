# 第二チャンネル コンセプト設計書（2026-11-23 確定版）
迷ったらこの1枚に戻る。ここにないことは足さない。変えるときは本人が決めて、日付を書いて直す。

## 1. 存在理由
**夜、通帳や将来の不安で心がざわつく50〜60代が、海外の名著の知恵で「お金と心の主導権」を取り戻す、静かな思考ラジオ。**
- ただの要約・お勉強チャンネルにはしない。視聴者の痛みをほどく場所にする
- 宇宙銀行（夜・眠り・金運を感覚でほどく）とは役割が別。こちらは「考え方」で仕組みを理解する

## 2. 目的
収益の安定化（宇宙銀行に約98%依存しているので、2本目の柱を作る）。
- 途中広告を入れる（15〜18分）
- オーディブルのアフィリエイト（概要欄の一番上にPR表記・YouTubeの「有料プロモーション」設定）
- 出口は今ある本だけ（新しい商品は作らない）

## 3. 誰に（ペルソナ）
- **50〜64歳の働く人・主婦**（宇宙銀行の視聴者の上位が55〜64歳）
- **いつ**：夜、一人の時間や寝る前。「このまま働き続けて大丈夫か」「頑張っているのに報われない」と不安になる瞬間
- **本音**：専門用語は頭に入らない。成功者の自慢話は疲れる。静かな声で、不安の正体を言葉にして、明日から少し楽になる考え方がほしい

## 4. 発信者（概要欄・プロフィール）
名前はヒュー。言い切り・厳しめ。家族の話と具体的な金額は出さない。
> ヒューです。『努力0だから貯まる！シンプル家計術』著者（Amazonレビュー★4.2）。FP3級。
> 時間を売って稼ぐ働き方は、働けなくなった日に止まります。
> だからわたしは、お金に働いてもらう仕組みを作っています。
> このチャンネルでは、海外の名著から、ビジネスオーナーと投資家の考え方と、それを支える心の仕組みを語ります。
（書名はAmazonのページで確認済み：『努力0だから貯まる！シンプル家計術: 節約したくても、できないママへ』著者名「シンプリスト ヒュー」・Kindle・★4.2／24件・11/23時点）

|---|---|---|
| ① 心の仕組み | 潜在意識・思考法（マーフィー、ナポレオン・ヒル など） | 入口。宇宙銀行の視聴者がいちばん反応する |
| ② お金の仕組み | ビジネスオーナー・投資家の考え方（金持ち父さん、サイコロジー・オブ・マネー、E-Myth など） | 芯。信頼と広告単価を上げる |

## 6. 制作の鉄則
1. **本の要約はしない**。「視聴者の痛み → なぜそうなるか → 名著が示す本質 → 今夜からできること」の順
2. **冒頭30秒に全力**。あいさつ・自己紹介はあと。最初に「これ、わたしのことだ」と思う問いを置く
3. **本人のひと言（★）を必ず1か所**（第2章の終わり・100〜150字）
4. 長さ2,500〜3,000字（No.7・話速0.9で15〜18分）。長い引用・細かい数字なし
5. 特定の投資商品を勧めない。結果を約束しない
6. 専門用語（BIマインドなど）は使うなら一言で説明する

## 7. 作り方
本人が本を選ぶ → AIが下書き → 本人が確認して★を書く → VOICEVOX No.7で読み上げ → 手持ちの音源1曲（Sunoの新曲は使わない）＋少し動きのある映像 → 非公開アップで著作権確認 → 公開。週1本まで。

## 8. やらないこと
- 毎日更新・テンポの速い要約（大手と同じ土俵に乗らない）
- もうけ話に見える言葉（「お金製造マシーン」などは自己紹介・タイトルに使わない）
- 眠り・金運BGM（宇宙銀行の役割）
- 新しい本・アプリ・noteを作る
