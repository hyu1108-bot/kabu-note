# 宇宙銀行 X（旧Twitter）ポストのルール

Claude Code 用。詳しい文面は `宇宙銀行_週間フロー.xlsx` の「ショート・X」シート。

## 基本ルール
- **ハッシュタグ込みで140字以内（厳守）**
- ハッシュタグは末尾に `#宇宙銀行 #金運` の2つ
- 語りかけ口調・やさしいです・ます調。煽らない（「今日だけ」などの焦らせる言葉は使わない）
- 「〇〇すると金運が上がる」と効果を約束しない
- 宇宙寄りの語彙（満ちる・めぐる・降り注ぐ）を使う。土のイメージ（根が張る 等）は使わない
- プラットフォームごとに文面を変える（YouTubeコミュニティ・Substackの横流しはしない）

## 役割
窓口ワークの「問いかけ」を1つ置いて、土曜18時の「宇宙銀行の窓口」ライブに誘う入口。

## 週の流れ
| 曜日 | 時刻 | 内容 |
|---|---|---|
| 月 | ― | 火曜分を予約（ショートと同じ問いかけ。ショートは火曜15:00公開） |
| 火 | 12:30 | 今週の問いかけ（2026-09-29から12:30。行き先テストのため毎週同じ時刻にそろえる） |
| 土 | 12:00 | 窓口リマインド（2026-10-03〜）「今週も、本当におつかれさまでした。／今夜18時から朝まで、宇宙銀行の窓口が開きます🌙／収入の安定を感じながら、ゆっくり眠れる11時間。／何もしなくて大丈夫です。聴くだけでどうぞ。」＋ライブURL（123字）。「紙とペンを用意して」は「聴くだけ」44%のため使わない |
| 日 | 任意 | ライブのチャットから記帳を1つ紹介（名前は伏せる） |

※土曜ライブの継続は金曜の分析で判断（2026-10-02）。続けない場合は土曜の行を見直す。
