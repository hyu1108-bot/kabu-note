# 使うのが怖い（2026-10-02 コミュニティ投稿）

```
🌙 宇宙銀行より

今朝、歩きながら気づいたことがあります。

少しずつ貯金が増えても、
お金を使うのが、やっぱり怖い。
毎日の支出が気になって、ちまちま、けちけちしてしまう。
心のどこかに、ブロックがあるみたいです。

でも、それはきっと自然なこと。
お金の不安は「金額」ではなく、
「減ること」に反応しているからです。

それに、慎重でいられたからこそ、
ここまで大切に守ってこられたんですよね。
その怖さは、あなたがお金を大切にしてきた証です。

だから、無理に消さなくて大丈夫。
わたしは今日から、こんな小さなことを試してみます。

・「使っていいお金」を先に決めておく
・払ったときは「減った」ではなく「めぐった」と言いかえる
・気持ちよく使えたことを、ひとつだけ覚えておく

お金は減るのではなく、めぐっていくもの。
あなたにも、そんな気持ちになることはありますか？

#宇宙銀行 #金運
```
