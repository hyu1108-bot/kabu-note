# 今週の音源チェックリスト（10/13〜10/19）

スクリプト：`bgm/audio_tools/onken.ps1`（使い方はファイルの一番上に書いてあります）

## 0. 最初に1回だけ
- [ ] パソコンで `ffmpeg -version` が動くか確認（動かなければインストール）
- [ ] `onken.ps1` を音源フォルダの近くに保存

## 1. SUNO（10/15 ダウンロードのリセットまでに）
- [ ] 「チャリン」のプロンプトで生成（CLAUDE.md の SUNO の項）
- [ ] 曲ページからダウンロード（Studio経由は無音になる）。最初の1曲で音が出るか確認
- [ ] フォルダ `1007_チャリン` に入れて、全部選んで F2 →「1007_チャリン」で連番に
- [ ] ダウンロード待ちの約20曲も同じようにダウンロード

## 2. IDチェック（公開の前日までに）
- [ ] `onken.ps1 check "（チャリンのフォルダ）"` を実行
- [ ] できた「IDチェック用.mp4」をYouTubeに**非公開**でアップ
- [ ] 著作権の欄を確認
- [ ] 申し立てがあれば、検出時刻と「_曲の順番.txt」を見比べて、その曲を捨てる
- [ ] 問題なかった曲だけ「IDチェック済み」フォルダへ
- [ ] 非公開の動画を削除

## 3. 3時間マスター
| 公開・配信 | 作る日 | 名前の例 | 済 |
|---|---|---|---|
| 10/15（木）17:00 3時間動画（臨時収入） | 10/14（水） | `1015_木曜` | [ ] |
| 10/16（金）17:00 3時間動画（高額当選） | 10/14（水） | `1016_金曜` | [ ] |
| 10/17（土）18:00 窓口ライブ（ループ用） | 10/15（木） | `1017_土曜ライブ` | [ ] |
| 10/18（日）17:00 3時間動画（不安解消） | 10/16（金） | `1018_日曜` | [ ] |
| 10/19（月）18:00 月曜ライブ（ループ用） | 10/17（土） | `1019_月曜ライブ` | [ ] |

- 毎回 `onken.ps1 master "（IDチェック済みのフォルダ）" 1015_木曜` のように実行
- 同じ曲の並びが続かないよう、曜日ごとに「IDチェック済み」から選ぶ曲を少し入れ替えるとよい
- 「_曲の順番.txt」は動画と一緒に保存しておく（申し立てが来たときの逆算用）
