# 音源づくり手順（ターミナル・コピペ用）

成功神殿・宇宙銀行（金運）どちらでも使える。PCの「ターミナル」（PowerShell）に貼るだけ。

## 貼るときの注意
- 1つの箱（```の中）を**まるごと**コピーして貼る
- 貼ったあと、最後の行が入力欄に残っていたら**Enterをもう1回**
- 赤い字が出ておかしくなったら、**Esc** → `cls` Enter で画面をきれいにしてからやり直す
- 動いている間（`PS C:\...>` が出ていない間）はターミナルを閉じない

---

## 0. 準備（最初の1回だけ）
```powershell
winget install --id Gyan.FFmpeg -e
```
終わったらターミナルを閉じて開き直す。

## 1. 曲を集めて、IDチェック用の動画を作る

**最初の3行だけ書き換える。**
- `$word`：ファイル名に入っている言葉（成功神殿なら `成功`、宇宙銀行なら `金運` など）
- `$name`：作るフォルダの名前
- `$img`：動画に使う画像（何でもよい。横長がおすすめ）

```powershell
$word = "金運"
$name = "金運_音源"
$img  = "C:\Users\ABC\Downloads\サムネ.png"

# ここから下は書き換えない ------------------------------------------
$dl  = "$env:USERPROFILE\Downloads"
$out = "$dl\$name"
New-Item -ItemType Directory -Force $out | Out-Null
# 使わない曲（Content IDに引っかかった曲）。増えたらここに足す
$ng = @("金運チャンネル0806その1 (1)")

$all = Get-ChildItem $dl -Recurse -File -Filter *.mp3 -ErrorAction SilentlyContinue |
  Where-Object { $_.Name -like "*$word*" -and $_.DirectoryName -notlike "$out*" -and ($ng -notcontains $_.BaseName) } |
  Sort-Object DirectoryName, Name
$seen = @{}; $files = @()
foreach ($f in $all) {
  $h = (Get-FileHash $f.FullName -Algorithm MD5).Hash
  if (-not $seen.ContainsKey($h)) { $seen[$h] = 1; $files += $f }
}
Write-Host "「$word」のMP3：$($all.Count) 個 → 重複を除いて $($files.Count) 曲" -ForegroundColor Yellow

if ($files.Count -eq 0) {
  Write-Host "曲が見つかりませんでした。`$word を見直してください" -ForegroundColor Red
} elseif (-not (Test-Path $img)) {
  Write-Host "画像が見つかりません：$img" -ForegroundColor Red
} else {
  [IO.File]::WriteAllLines("$out\list.txt", [string[]]($files | ForEach-Object { $_.FullName }))
  # YouTubeは12時間まで。1本120曲（7〜8時間）ずつに分けてIDチェック用の動画を作る
  $part = 0
  for ($i = 0; $i -lt $files.Count; $i += 120) {
    $part++
    $chunk = $files[$i..([math]::Min($i + 119, $files.Count - 1))]
    $lines = $chunk | ForEach-Object { "file '" + ($_.FullName -replace "'", "'\''") + "'" }
    [IO.File]::WriteAllLines("$out\IDチェック_$part.txt", [string[]]$lines)
    Write-Host "IDチェック_$part を作成中（$($chunk.Count) 曲）… 10〜20分かかります" -ForegroundColor Yellow
    ffmpeg -hide_banner -loglevel error -y -f concat -safe 0 -i "$out\IDチェック_$part.txt" -c:a libmp3lame -b:a 192k "$out\IDチェック_$part.mp3"
    ffmpeg -hide_banner -loglevel error -y -loop 1 -framerate 1 -i $img -i "$out\IDチェック_$part.mp3" `
      -vf "scale=1280:720:force_original_aspect_ratio=decrease,pad=1280:720:(ow-iw)/2:(oh-ih)/2" `
      -c:v libx264 -tune stillimage -pix_fmt yuv420p -c:a aac -b:a 192k -shortest "$out\IDチェック_$part.mp4"
    if (Test-Path "$out\IDチェック_$part.mp4") { Write-Host "IDチェック_$part.mp4 できました" -ForegroundColor Green }
    else { Write-Host "IDチェック_$part.mp4 が作れませんでした" -ForegroundColor Red }
  }
  explorer $out
}
```

### できるもの（ダウンロード\〇〇_音源）
- `IDチェック_1.mp4`、`IDチェック_2.mp4`…：**これを非公開でアップ**して「制限事項」欄を確認
- `IDチェック_1.txt`…：その動画に入っている曲の順番（申し立ての時刻から曲を調べるのに使う）
- `list.txt`：集めた全曲の一覧

### 申し立てが付いたら
検出された**時刻**と、何番の動画かをClaudeに伝える → どの曲か調べてもらう →
その曲名を上の `$ng = @(...)` に足して、**1. をもう一度**やる（引っかかった曲は入らなくなる）

## 2. IDチェックが終わったら、3時間版を何本か作る

**最初の2行だけ書き換える。** `$name` は 1. と同じにする。

```powershell
$name  = "金運_音源"
$count = 7

# ここから下は書き換えない ------------------------------------------
$out   = "$env:USERPROFILE\Downloads\$name"
$files = [IO.File]::ReadAllLines("$out\list.txt")
Write-Host "使える曲：$($files.Count) 曲" -ForegroundColor Yellow
1..$count | ForEach-Object {
  $n = $_
  $pick  = $files | Get-Random -Count ([math]::Min(60, $files.Count))
  $lines = $pick | ForEach-Object { "file '" + ($_ -replace "'", "'\''") + "'" }
  [IO.File]::WriteAllLines("$out\3時間_$n.txt", [string[]]$lines)
  ffmpeg -hide_banner -loglevel error -y -stream_loop -1 -f concat -safe 0 -i "$out\3時間_$n.txt" -t 03:00:00 -c:a libmp3lame -b:a 192k "$out\3時間_$n.mp3"
  if (Test-Path "$out\3時間_$n.mp3") { Write-Host "3時間_$n.mp3 できました" -ForegroundColor Green }
  else { Write-Host "3時間_$n.mp3 が作れませんでした" -ForegroundColor Red }
}
explorer $out
```

### できるもの
- `3時間_1.mp3`〜：毎回ちがう曲の組み合わせ・順番の3時間版。Filmoraに入れて画像と合わせる
- `3時間_1.txt`〜：その3時間版に入っている曲（あとで申し立てが付いたときに調べる用）

### 注意
- 曲が60曲より少ないときは、ある曲を全部使って3時間になるまでくり返す
- 3時間版も、公開前に**非公開でアップして著作権の欄を確認**してから予約公開（今までどおり）
- 宇宙銀行はライブ用に11時間が要るときは、`-t 03:00:00` を `-t 11:00:00` に変える

## 3. テロップ入りの3時間動画を作る（成功神殿）

冒頭47秒にテロップ3枚（1枚15秒・1秒フェード）→ 残りは同じ画像を10秒ずつくり返し → 音源と合わせて3時間。
文字は**クリーム色の黄色＋太い黒ふち**、丸ゴシック（HG丸ゴシックM-PRO。なければ游ゴシック太字）、画面の中央より少し下。

**最初の3行だけ書き換える。** `$t2` の `` `n `` は改行。

```powershell
$n   = 1
$img = "C:\Users\ABC\Desktop\成功神殿画像\1.png"
$t2  = "昨日の続きを`n今日も少しだけ。それで十分です"

# ここから下は書き換えない ------------------------------------------
$t1  = "ようこそ、成功神殿へ`n3時間、朝の光と一緒に整えていきます"
$t3  = "さあ、大丈夫`nあなたの一日がはじまります"
$w   = "$HOME\Desktop\3時間"
$tmp = "$w\テロップ作業_$n"
New-Item -ItemType Directory -Force $tmp | Out-Null
$u = New-Object Text.UTF8Encoding $false
$font = @("HGRSGU.TTC","YuGothB.ttc","meiryob.ttc","meiryo.ttc","msgothic.ttc") | ForEach-Object { "C:\Windows\Fonts\$_" } | Where-Object { Test-Path $_ } | Select-Object -First 1
Copy-Item $font "$tmp\font.ttc" -Force
$bg = "bg" + [IO.Path]::GetExtension($img)
if (-not (Test-Path -LiteralPath $img)) { Write-Host "画像が見つかりません：$img" -ForegroundColor Red; return }
Copy-Item -LiteralPath $img "$tmp\$bg" -Force
$base = "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080,format=yuv420p"
$vf = @($base)
$texts = @($t1, $t2, $t3)
for ($i = 0; $i -lt 3; $i++) {
  [IO.File]::WriteAllText("$tmp\t$i.txt", $texts[$i], $u)
  $s = 1 + $i*15; $e = $s + 14
  $vf += "drawtext=fontfile=font.ttc:textfile=t$i.txt:fontsize=96:fontcolor=0xF6E27A:borderw=8:bordercolor=black@0.85:line_spacing=30:text_align=C:x=(w-text_w)/2:y=(h-text_h)/2+120:alpha='if(lt(t,$s),0,if(lt(t,$s+1),t-$s,if(lt(t,$e-1),1,if(lt(t,$e),$e-t,0))))'"
}
[IO.File]::WriteAllText("$tmp\vf.txt", ($vf -join ","), $u)
Push-Location $tmp
ffmpeg -nostdin -loglevel error -y -loop 1 -framerate 30 -i $bg -/vf vf.txt -t 47 -c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p part1.mp4
ffmpeg -nostdin -loglevel error -y -loop 1 -framerate 30 -i $bg -vf $base -t 10 -c:v libx264 -preset veryfast -crf 20 -pix_fmt yuv420p part2.mp4
$l = @("file 'part1.mp4'") + (1..1100 | ForEach-Object { "file 'part2.mp4'" })
[IO.File]::WriteAllLines("$tmp\list.txt", [string[]]$l)
ffmpeg -nostdin -loglevel error -y -f concat -safe 0 -i list.txt -i "$w\成功神殿_3時間_$n.m4a" -map 0:v -map 1:a -c copy -t 03:00:00 -movflags +faststart "$w\成功神殿_完成_$n.mp4"
Pop-Location
if (Test-Path "$w\成功神殿_完成_$n.mp4") { Write-Host "完成：成功神殿_完成_$n.mp4" -ForegroundColor Green; explorer $w } else { Write-Host "失敗しました" -ForegroundColor Red }
```

2枚目のテロップ（1週目）は `bgm/成功神殿_テスト1週目.md` の表を使う。
