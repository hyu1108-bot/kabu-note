# 大きな石のワーク（ツボアプリ）まとめ

## 目的
新しい年に向けて、オンラインのグループで「自分にとって本当に大切なもの」を見つけるワーク。
「ツボに大きな石・小石・砂を入れるとき、大きな石から入れると全部入る」というお話に見立てている。

## アプリの流れ
1. はじめに：ツボのお話と2つのツボの絵（砂から入れる→大きな石が入らない／大きな石から→全部入る）
2. 大切なもの（石）を9つ入力
3. 「横に置く」を3回：3つ → 3つ → 2つ（各回のあと「残りは〇つです」と表示し、司会の合図で「次へすすむ」）
4. 最後に残った1つ＝「あなたの大きな石」。ふりかえりの問い3つ
5. 「来年いちばん先にツボへ入れるために、やってみたい小さなこと」を1つ書く
6. 「ツボに入れてみる」：大きな石（最後の1つ）→中くらいの石（3回目に置いた2つ）→小石（2回目の3つ）→砂（1回目の3つ）の順にツボへ入るアニメーション →「9つ ぜんぶ、ツボに入りました」
7. まとめ表、メモをコピー、はじめから

## デザイン・言葉のルール
- 明るく前向き（クリーム〜あたたかいオレンジのグラデーション、ダークモードでも明るいまま）
- 「手放す」は使わず「横に置く」
- 入力内容はその人の端末の中だけ（localStorage）。どこにも送らない
