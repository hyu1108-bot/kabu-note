### アプリの流れ
1. はじめに：ツボのお話と2つのツボの絵（砂から入れる→大きな石が入らない／大きな石から→全部入る）
2. 大切なもの（石）を9つ入力（キーワード30個から選んでもよい）
3. 「あとで入れる石」を3回選ぶ：3つ → 3つ → 2つ（各回のあと「残りは〇つです」、司会の合図で「次へすすむ」）
4. 最後に残った1つ＝「あなたの大きな石」。ふりかえりの問い3つ（入力欄つき。まとめとメモにも出る）
5. 「来年いちばん先にツボへ入れるために、やってみたい小さなこと」を1つ書く
6. 「ツボに入れてみる」：大きな石 → 中くらいの石（3回目の2つ）→ 小石（2回目の3つ）→ 砂（1回目の3つ）の順に入るアニメーション →「9つ ぜんぶ、ツボに入りました」
7. まとめ表、メモをコピー、はじめから

### 司会台本の流れ（約75分）
はじめに（約束3つ＋ツボのお話）5分 → 9つ書く10分 → あとで入れる石を3回20分 → ブレイクアウトでシェア20分 → 全体シェア＋来年の一歩＋「ツボに入れてみる」15分
